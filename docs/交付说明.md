## 二、验证记录

### 1. 编译

- 工具链：Visual Studio Community 2026（MSBuild 18.10）、.NET Framework 4.8 参考程序集
- 命令：`msbuild CampusLink.csproj -t:Restore,Build -p:Configuration=Debug`
- 结果：**0 错误**；NuGet 还原 `WPF-UI 4.3.0` + `Newtonsoft.Json 13.0.3` 成功

### 2. 协议层自动化测试

`tests/CoreTests` 用 TcpListener 起了一个 mock 门户，覆盖真实请求/响应格式，**46 项全部通过**：

- 编码：`encodeURIComponent` 语义（保留 `-_.!~*'()`）、中文 UTF-8、百分号、双重编码
- MAC 归一化（去分隔符 + 大写）
- DPAPI 加密/解密往返；`AccountProfile` 序列化不含明文密码
- JSON 容错：前后垃圾字符、字符串数字、字符串布尔
- RSA：自造密钥对验证「反转 + 16 位小端分块 + 无填充」可被私钥还原；`密码+分隔符+MAC` 拼接正确
- 探测：302 `index.jsp?...` 提取 queryString/MAC；`redirectortosuccess.jsp` 判在线；连接失败不抛异常
- 登录：`passwordEncrypt=false` 明文、`true` 时提交定长 RSA 密文；请求体确认是双重编码；失败信息带 `queryString` 排错提示
- 保活 / 无感注册（MAC 归一化）/ 解绑 / 下线 / 下线全部会话（单次编码）/ getOnlineUserInfo / getServices / pageInfo
- 自助服务：公钥+验证码获取、登录成功、验证码错误、密码错误三种分支判定

运行结果：`通过 46 项，失败 0 项`（含账号持久化、在线语义、在线账号识别、网卡枚举）。

### 3. 界面验证

在本机启动程序并逐页截图（`docs/screenshots/`），再用 UI Automation 逐项点检：

- 账号页：默认只显示卡片；点「添加账号」才弹表单；「编辑」「删除账号」可用；删除会弹二次确认
- 协议诊断：账号存在时五个接口按钮均可点击（此前因命令未刷新 CanExecute 一直是灰的）
- 自助服务：账号下拉框来自「账号」页，学号只读、密码取保存值
- 打开数据目录/日志目录：UI Automation 触发后日志写入 `已打开目录：...`
- 托盘：UIA 在任务栏溢出区找到 `CampusLink` 按钮（Windows 11 默认折叠）
- 单实例：第二次启动不产生新进程，会唤醒已有窗口
- 重启：账号配置从 `accounts.json` 正常载入（日志 `已载入 N 个账号`）

### 4. 现场网络

测试机当前处于校园网已认证状态：`GET http://222.201.54.55/` 返回 `302 → /eportal/redirectortosuccess.jsp`，程序识别为 `在线·免认证`（并明确提示「本次没有校验账号密码」）。

> 未做真实账号密码登录：该 MAC 已被 AC 放行，校园网不会下发 `queryString` 供登录；要触发真实登录需要先让该 MAC 掉线（会中断你当前的网络），所以没有擅自操作。

## 八、已知限制

1. **`passwordEncrypt` 真实取值未确认**：资料里未能拿到真实登录页隐藏字段。已实现「自动 / 强制明文 / 强制 RSA」三种模式与 `>`、`>>` 两种分隔符可切换，并提供诊断页核对。
2. **服务列表**：广大现场 `getServices` 返回空数组，`service` 参数默认留空；如报「请选择服务」，可从诊断页拿到服务名后填进账号设置。
3. **自助服务验证码**：离线没有可靠的 C# OCR 方案（资料里的 `ddddocr` 是 Python 库），因此保留人工输入；登录后的改密/余额页面是 JSF 动态页，未做接口化，走浏览器。
4. **多账号 + 网卡**：同一块网卡下多个账号会互相顶掉；真实多账号聚合需要为每个账号绑定不同网卡。
5. **托盘图标**依赖 WinForms `NotifyIcon`（.NET Framework 自带，不需要额外 NuGet）；Win11 默认折叠，需要用户手动打开常驻。
6. **密码校验**：MAC 已注册无感时门户不会下发 `queryString`，登录接口走不到；想验密码只能用「自助服务 → 登录校验」（需验证码），或先解绑 MAC 让 AC 重新拦截。
7. **管理员权限**：清单要求管理员运行；单实例互斥只在同一会话内生效（管理员实例之间正常）。
